# Logo

`man/figures/logo.svg` is generated by `make_hex_salad.py`, which uses the
berg drawing in `make_logo.py`. The name comes from the list of sea-ice
terms: a tabular berg is a flat-topped slab calved from an ice shelf, a
table above the waterline with most of its mass, here an array of chunks,
below it.

To regenerate (needs Python 3, Pillow and the DejaVu fonts):

```sh
cd tools/logo
python3 make_hex_salad.py
cp tabularberg-hex-salad.svg ../../man/figures/logo.svg
rsvg-convert -w 480 ../../man/figures/logo.svg -o ../../man/figures/logo.png
```

The terms list, colours and the random seed for the row offsets are at
the top of `make_hex_salad.py`.
